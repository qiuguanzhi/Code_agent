标题：Agent 主循环逻辑

节点（共 8 个）：
1. 启动：run_agent() 开始，初始化快照
2. 判断1：用户停止？ → 是 → 结束
3. 判断2：超时（20分钟）？ → 是 → 结束
4. 判断3：步数上限（默认200）？ → 是 → 弹窗：继续（+50步）或停止
5. 判断4：重复调用？ → 是 → 结束
6. 调用模型：Provider.complete()
7. 判断5：有 tool_calls？ → 否 → 正常完成，结束
8. 执行工具：ToolRegistry.execute_one_call() → 步数+1 → 回到判断1

分支说明：
- 判断3：继续 → 回到判断1；停止 → 结束
- 判断5：有工具 → 执行工具 → 回到判断1；无工具 → 正常结束
